# EmbeddedAI_STM32 – Wake Word Detection on STM32H7

Real-time wake word detection running entirely on a **Nucleo-H743ZI2** board,
using an **INMP441** I²S MEMS microphone, **Edge Impulse** for model training,
and **STM32Cube.AI (X-CUBE-AI)** for on-device neural network inference.

---

## Hardware requirements

| Item | Details |
|------|---------|
| Development board | STM32H743ZI2 Nucleo (or compatible H7 board) |
| Microphone | INMP441 I²S MEMS module |
| USB cable | micro-USB (ST-LINK) |
| Jumper wires | 5× female–female |

### INMP441 wiring

| INMP441 pin | Nucleo-H743ZI2 pin | Signal |
|------------|-------------------|--------|
| VDD | 3.3 V (CN8-7) | Power |
| GND | GND (CN8-11) | Ground |
| WS | PB12 (CN10-16) | I2S2_WS |
| SCK | PB13 (CN10-30) | I2S2_CK |
| SD | PB15 (CN10-26) | I2S2_SDI |
| L/R | GND | Left channel select |

## Quick-start build guide

### Step 1 – Train the model

Follow **`WakeWord_STM32H7/EdgeImpulse/README.md`** to:
1. Record wake word and background noise samples in Edge Impulse Studio.
2. Design the Impulse (MFCC → 1-D Conv classifier).
3. Train and validate the model (aim ≥ 95 % accuracy).
4. Export as **STM32Cube.AI Library** (`.tflite` or `.onnx`).

### Step 2 – Open the project in STM32CubeIDE

```
File → Import → Existing Projects into Workspace
→ Browse to WakeWord_STM32H7/
→ Finish
```

### Step 3 – Import the model with X-CUBE-AI

1. Double-click `WakeWord_STM32H7.ioc`.
2. Navigate to:
   **Pinout & Configuration → Software Packs → X-CUBE-AI → Artificial Intelligence**
3. Click **Add network** → browse to the exported `.tflite` file.
4. Name the network **`network`** (must match `#include "network.h"` in the code).
5. Click **Analyse** – review Flash / RAM usage.
6. Click **Generate Code** – this creates `network.c/h` and `network_data.c/h`
   in `X-CUBE-AI/App/`.

### Step 4 – Build and flash

```
Project → Build All   (Ctrl+B)
Run → Debug           (F11)  – or use Run → Run  for release flashing
```

### Step 5 – Verify

Open a serial terminal at **115 200 baud, 8N1** on the ST-LINK virtual COM port:

```
====================================================
  Wake Word Detection – STM32H743ZI2 + INMP441
====================================================
[XCUBEAI] Network: network  (rev ...)
[XCUBEAI] In : 637 × float32
[XCUBEAI] Out: 2 × float32
[OK]  Audio capture started at 16000 Hz
[OK]  Say your wake word...

[WW] *** WAKE WORD DETECTED ***  (score=0.987)
```

The green LED (**LD1**) blinks for 500 ms on each detection.

## Application architecture

```
┌──────────────────────────────────────────────────────────┐
│  INMP441 (I2S, 16 kHz, 24-bit)                          │
│       │  I2S2 + DMA1 (circular, half-word)              │
│  audio_capture.c                                         │
│       │  int16_t PCM ring buffer                        │
│  audio_processing.c (CMSIS-DSP)                          │
│       │  MFCC: pre-emphasis → FFT → mel → log → DCT     │
│       │  output: 49 frames × 13 coeffs = 637 float32    │
│  wake_word_detection.c (X-CUBE-AI)                       │
│       │  ai_network_run()                               │
│       │  softmax [noise, wake_word]                     │
│  main.c                                                  │
│       │  score ≥ threshold → blink LD1 + UART print     │
└──────────────────────────────────────────────────────────┘
```

### Key parameters (tunable in `Core/Inc/main.h`)

| `#define` | Default | Description |
|-----------|---------|-------------|
| `AUDIO_SAMPLE_RATE_HZ` | 16 000 | Microphone sample rate |
| `AUDIO_FRAME_MS` | 32 | FFT window length (ms) |
| `AUDIO_HOP_MS` | 16 | Frame hop / inference stride (ms) |
| `WAKEWORD_THRESHOLD` | 200 | Detection threshold (0–255) |
| `WAKEWORD_LED_DURATION_MS` | 500 | LED blink duration after detection |

### Key parameters (tunable in `Core/Inc/audio_processing.h`)

| `#define` | Default | Description |
|-----------|---------|-------------|
| `NUM_MFCC_COEFFS` | 13 | MFCC coefficients per frame |
| `NUM_MFCC_FRAMES` | 49 | Frames per inference window (≈ 800 ms) |
| `NUM_MEL_FILTERS` | 26 | Mel filter bank channels |
| `FFT_SIZE` | 512 | Real FFT length (must be power of 2) |
| `PRE_EMPHASIS_COEFF` | 0.97 | First-order pre-emphasis |

> All MFCC parameters must match the settings used in your Edge Impulse project.

## Memory footprint (estimated)

| Region | Usage |
|--------|-------|
| Flash (code + HAL) | ~80 KB |
| Flash (AI weights, int8 model) | ~30–100 KB |
| RAM – activations buffer | ~10–40 KB |
| RAM – PCM + MFCC buffers | ~10 KB |
| RAM – DMA buffer (D2 SRAM) | ~1 KB |
| **Total RAM** | **~60–90 KB** (of 512 KB AXI SRAM) |

The STM32H743 has 2 MB Flash and 1 MB total SRAM, so there is ample headroom.

## Troubleshooting

| Symptom | Likely cause | Fix |
|---------|-------------|-----|
| No UART output | Wrong COM port or baud rate | Use 115 200 8N1; check Device Manager |
| `[ERR] Network initialisation failed` | `network.c/h` not generated | Re-run X-CUBE-AI code generation |
| Constant false positives | Threshold too low | Raise `WAKEWORD_THRESHOLD` |
| Wake word not detected | Threshold too high or model undertrained | Lower threshold; retrain with more data |
| Garbled / no audio | I2S wiring | Double-check INMP441 pin connections |
| `HardFault` at startup | Activation buffer too small | Re-check `AI_NETWORK_DATA_ACTIVATIONS_SIZE` |
